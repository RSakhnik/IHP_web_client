# IHP_web_client

**Сборка:**
```bash
npm ci --legacy-peer-deps
npm run build-prod
```

AI/BIM-помощник для Pilot Web, работающий в правой панели BIM-модели.

Frontend взаимодействует с AI Services через `PSIM_AI_Services_Connector`; для отладки также предусмотрен режим прямых HTTP-запросов.

**Поддерживает:**

- диалог с AI-помощником с сохранением контекста сессии
- поиск BIM-элементов по DSL-запросам
- поиск с последующей визуализацией найденных элементов
- визуализацию предыдущего поиска или текущего выделения
- получение свойств выбранных/найденных элементов
- действия с BIM-элементами, включая подсветку и изоляцию
- проверку соединений трубопроводов
- построение подробных и итоговых отчётов
- предпросмотр отчётов и экспорт в Excel
- потоковую обработку ответов через SSE
- отмену запросов, повторный запуск действий и пользовательскую оценку ответов
- диагностический режим с трассировкой tool calls и логами выполнения

Используется совместно с backend-коннектором `PSIM_AI_Services_Connector`.

**Стек:** Vue 3; TypeScript; ASCON Pilot Web SDK; Pilot Web 2D/3D; Webpack Module Federation; RxJS; XLSX; JSZip
